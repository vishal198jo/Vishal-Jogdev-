Cloudflare R2 CORS Action Required

A "Network Failure" error means CORS needs to be enabled on your Cloudflare R2 bucket. Follow these simple 1-minute steps:

  1. Log in to your Cloudflare Dashboard and click R2 on the left.
  2. Click on your bucket name vishaljogedeo.
  3. Go to the Settings tab at the top.
  4. Scroll down to the CORS Policy section and click "Add CORS Policy".
  5. Copy the entire JSON block below and paste it into the editor:
[
  {
    "AllowedOrigins": [
      "*"
    ],
    "AllowedMethods": [
      "GET",
      "PUT",
      "POST",
      "DELETE",
      "HEAD"
    ],
    "AllowedHeaders": [
      "*"
    ],
    "ExposeHeaders": []
  }
]

This policy tells Cloudflare to trust and allow file uploads directly from your Admin website/portal to the secure storage bucket.
